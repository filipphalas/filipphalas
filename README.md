### SovoLM — Chess Move Prediction Model *(In Progress)*

A transformer model in PyTorch that learns to play chess from human games.

- **Model:** Decoder-only transformer that predicts the next move from UCI move tokens.
- **Data:** Trained on public Lichess game databases.
- **Inference:** Legal-move masking so the model only plays valid moves.
- **Goal:** Runs inside SovoChess as a playable, human-like opponent.
